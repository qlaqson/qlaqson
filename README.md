# QLAQSON

**Messenger. Identity. Proof.**

QLAQSON is a privacy-first blockchain-native messaging and communication platform.

It is being designed around three core principles:

- encrypted conversations
- user-owned identity
- verifiable actions

The project separates private communication from public verification so that message content does not need to become public blockchain data.

## Current status

**MVP Alpha 0.1 — In development**

Current work includes:

- persistent QS ID
- multi-device identity
- encrypted messaging
- private proof layer
- public verification ledger
- implementation and validation of the MVP architecture

## Development approach

QLAQSON is being built step by step.

Major technical decisions, milestones and selected public components will be documented as the project evolves.

The goal is to show what has actually been decided, implemented and tested — not just what is planned.
